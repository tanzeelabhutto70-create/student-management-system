# Student Record Management System

## About the Project
This project is developed for the CodeNova Python Programming Internship - Batch 01.

It is a simple Python application used to manage student records.

## Features
- Add Student
- View Students
- Search Student by ID
- Update Student Information
- Delete Student
- Save records in a JSON file
- Input validation and error handling

## Technologies Used
- Python
- JSON
- File Handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python student_management.py

## Data Storage
Student records are stored in a file named students.json.
